How it works

Obsidian is built on Electron, so the plugin asks Electron's desktopCapturer for your screens and windows and records the one you pick with the browser's MediaRecorder. A region is cut out of each frame before it is encoded, so the file only holds the area you drew.

Chromium always draws the mouse pointer and ignores requests to leave it out. When you turn the cursor off, cap-sort swaps in a small Rust helper built on scap that captures frames without it, using ScreenCaptureKit on macOS, Windows.Graphics.Capture on Windows and PipeWire on Linux. Cropping, audio and encoding stay the same either way.

Video is capped at 1920×1200 and encoded with AV1 when your system supports it (VP9 or VP8 otherwise). The mic and system audio are mixed into one Opus track at 64 kbps.

Install

  1. Download main.js, manifest.json and styles.css from the repository.
  2. Put them in <vault>/.obsidian/plugins/cap-sort/.
  3. Enable cap-sort under Settings → Community plugins.
  4. On macOS, allow Obsidian under Privacy & Security → Screen Recording when asked.

What goes over the network

Only the cursor helper, and only after you click Download helper. It comes from this project's GitHub releases and is stored in the plugin folder. Recordings never leave your vault.

npm install && npm run build
cd helper && cargo build --release
